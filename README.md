# «Քրեագետ» — сайт центра судебных и независимых экспертиз

Laravel 13 (PHP 8.3). Языки: армянский (по умолчанию), русский, английский.

## Что есть

**Сайт**
- Главная: первый экран, принципы, «О центре», 10 направлений экспертизы, для кого, этапы работы, статьи, FAQ, контакты с картой и формой.
- Страница каждого направления (`/services/{slug}`) с формой заявки по нему.
- Статьи (`/articles`), контакты (`/contact`), переключатель языка HY / RU / EN.
- Instagram, Facebook, телефоны, почта и адрес выводятся из настроек.

**Клиенты**
- Регистрация и вход, личный кабинет.
- Отправка заявок (гостем или из кабинета), номер заявки вида `QR-26-00001`.
- В кабинете: статус, стоимость, срок, история и комментарии специалиста, свои комментарии.

**Онлайн-чат + Telegram**
- Виджет чата на всех страницах.
- Каждое сообщение посетителя приходит в Telegram (лично админу или в группу).
- Ответ из Telegram: **Reply** на сообщение бота или команда `/r 12 текст`. Ответ сразу появляется у посетителя.
- Команды бота: `/chats` (открытые чаты), `/requests` (новые заявки), `/id` (узнать Chat ID).
- Новые заявки, регистрации и комментарии клиентов тоже приходят в Telegram.
- Отвечать можно и из админ-панели.

**Админ-панель** (`/admin`)
- Обзор: счётчики, график заявок за 14 дней, разбивка по статусам и отделам, последние заявки и чаты.
- Заявки: поиск, фильтры (статус, отдел, приоритет, ответственный, даты), сортировка, массовые действия, экспорт CSV (открывается в Excel), карточка с назначением ответственного, ценой, сроком, внутренней заметкой, комментариями (видимыми клиенту или внутренними), историей.
- Онлайн-чат: список с непрочитанными, переписка в реальном времени, звуковое уведомление, закрытие и удаление.
- Пользователи: роли «клиент», «менеджер» (заявки и чат) и «администратор», блокировка, смена пароля.
- Контент: отделы/услуги, статьи, FAQ, каждое на трёх языках.
- Настройки: контакты, соцсети, тексты главной, Telegram-бот, включение и выключение чата и регистрации, SEO, код аналитики.
- Журнал действий.

Первый вход: `admin@qreaget.am` / пароль из `ADMIN_PASSWORD` (если не задан: `Qreaget2026!`). **Смените пароль сразу после входа** (Админ → Пользователи).

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

## Деплой на Vercel

На Vercel нет постоянного диска, поэтому база данных внешняя (Postgres).

1. **Import Project** → выберите репозиторий `790azat/qreaget`. Framework Preset: **Other**. Остальное оставьте по умолчанию, всё нужное уже в `vercel.json` (runtime `vercel-php@0.7.4`, PHP 8.3).
2. **Storage → Create Database → Neon (Postgres)** и подключите к проекту. Vercel сам добавит `DATABASE_URL`, его подхватит Laravel.
3. **Settings → Environment Variables** добавьте:
   | Ключ | Значение |
   |---|---|
   | `APP_KEY` | вывод `php artisan key:generate --show` |
   | `APP_URL` | `https://ваш-домен.vercel.app` |
   | `INSTALL_KEY` | любая длинная случайная строка |
   | `ADMIN_PASSWORD` | пароль администратора |
   | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | по желанию (можно задать в админке) |
4. **Redeploy**, затем один раз откройте `https://ваш-домен/install/<INSTALL_KEY>`: создаются таблицы и стартовые данные. После этого удалите `INSTALL_KEY` из переменных.

## Деплой на SmartApe (обычный хостинг)

Требования: PHP 8.3, MySQL (есть на всех тарифах SmartApe).

1. Панель SmartApe → **Сайты**: выберите PHP **8.3**.
2. **Базы данных → MySQL**: создайте базу и пользователя.
3. Загрузите файлы одним из способов:
   - **Через SSH** (рекомендуется):
     ```bash
     cd ~ && git clone https://github.com/790azat/qreaget.git
     cd qreaget && composer install --no-dev --optimize-autoloader
     cp deploy/.env.smartape.example .env && php artisan key:generate
     # заполните DB_* и ADMIN_PASSWORD в .env
     php artisan migrate --seed --force
     php artisan config:cache && php artisan route:cache && php artisan view:cache
     ```
   - **Без SSH**: загрузите готовый архив `qreaget-smartape.zip` (в нём уже есть `vendor/`) через файловый менеджер или FTP, распакуйте, переименуйте `deploy/.env.smartape.example` в `.env` и заполните. `APP_KEY` можно сгенерировать здесь: `php artisan key:generate --show`. Затем откройте `https://домен/install/<INSTALL_KEY>`.
4. **Корневая папка сайта**: в панели укажите `qreaget/public` как директорию сайта. Если это невозможно, залейте проект прямо в папку сайта: корневой `.htaccess` сам перенаправит запросы в `public/` и закроет служебные файлы.
5. Права на запись: `storage/` и `bootstrap/cache/` (755 или 775).
6. В админке: **Настройки и Telegram** → вставьте токен бота → «Установить webhook» → `/start` боту → вставьте Chat ID → «Тест».

### Обновление на SmartApe
```bash
cd ~/qreaget && git pull && composer install --no-dev -o && php artisan migrate --force && php artisan optimize
```

## Подключение Telegram-бота

1. В [@BotFather](https://t.me/BotFather): `/newbot` → получите токен.
2. Админка → Настройки и Telegram → вкладка «Telegram» → вставьте токен → Сохранить → **Установить webhook**.
3. Напишите боту `/start`: он ответит вашим Chat ID. Для группы добавьте бота в группу и напишите `/id`.
4. Вставьте Chat ID → Сохранить → **Тест**.

Webhook должен быть доступен по HTTPS (на Vercel и SmartApe с SSL это так).
