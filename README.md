# «Քրեագետ» — сайт центра судебных и независимых экспертиз

Laravel 13, PHP 8.3.

## Сделано

- Структура проекта, база данных
- Шапка, подвал, стили
- Главная: первый экран, «О центре», направления экспертизы, контакты
- Форма заявки (заявки сохраняются в базе)
- Главная: «Как мы работаем», «Кому помогаем», цифры в «О центре»

## Дальше

- Страницы направлений, отдельная страница контактов
- Остальные направления экспертизы
- Статьи, личный кабинет, онлайн-чат, панель администратора
- Русская и английская версии

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```
