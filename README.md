# «Քրեագետ» — сайт центра судебных и независимых экспертиз

Laravel 13, PHP 8.3.

## Сделано

- Структура проекта, база данных
- Шапка, подвал, стили
- Главная: первый экран, «О центре», направления экспертизы, контакты
- Форма заявки (заявки сохраняются в базе)
- Главная: «Как мы работаем», «Кому помогаем», цифры в «О центре»
- Страница всех направлений и отдельные страницы каждого направления
- Отдельная страница контактов, полный подвал
- Все 10 направлений экспертизы
- Частые вопросы (FAQ) на главной
- Статьи: список, страница статьи, блок на главной
- Уведомления о новых заявках в Telegram (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в `.env`)

## Дальше

- Русская и английская версии
- Регистрация, личный кабинет
- Панель администратора, онлайн-чат

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```
